# UI/UX Max Pro

A premium UI/UX toolkit and productivity CLI for design-focused developers.

## Features
- Global CLI installation
- Quick project status checks
- Design workflow automation
- Clean command-line experience
- Ready for extension with extra UI utilities

## Installation

Install globally from the project directory:

```bash
npm install -g .
```

Then run:

```bash
ui-ux-max-pro
```

## Usage

```bash
ui-ux-max-pro
ui-ux-max-pro --dev
```
